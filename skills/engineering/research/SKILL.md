# Research

## Evidence and artifact

Define the question and the decision the research needs to support.
Use relevant primary sources: official documentation, source code, specifications, or first-party APIs.
Open the sources behind material claims. Distinguish sourced facts, inference, and unresolved questions.

Save one focused Markdown note where the repository keeps research, or use a suitable path when no convention exists.
Include the answer, supporting links, and limitations that affect the decision. Match existing documentation metadata.

If the user requests delegation and useful independent work remains, assign the research to a background agent.
Otherwise, conduct it directly.

## Completion

The note answers the question to the extent supported by available evidence and gives a source for each material factual claim.
Return its path and the finding that matters to the user's decision.
