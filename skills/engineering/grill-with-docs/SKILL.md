# Grill With Docs

## Interview and records

Use [grilling](../grilling/SKILL.md) for the interview.
Use [domain-modeling](../domain-modeling/SKILL.md) when a domain term or architectural decision needs recording.
Create documentation as agreements emerge; preserve unresolved choices as open questions.

## Completion

Finish when the user confirms the shared understanding and the agreed records are saved.
Report their paths and remaining questions. Implementation follows the interview's authorization boundary.
